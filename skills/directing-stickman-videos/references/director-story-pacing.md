# A1–A5 narrative and pacing

Read before Phase A and preserve the approved decisions in Phase B. This file owns generic Director narrative and visual-density rules. Selected-style storytelling, drawing and continuity rules take precedence. A6 and B retain their own contracts.

## Choose the structure by purpose

State the chosen structure briefly in Phase A; infer it from the source and goal without adding an intake gate.

- Explanation: concrete question or example → mechanism → evidence/example → useful takeaway.
- Tutorial: desired result → prerequisites → ordered steps → demonstrated result and common pitfall.
- Story/comedy: setup → conflict/escalation → consequence or payoff. Preserve reaction pauses and intentional reveals.
- Promotion: audience problem → demonstrated benefit → supported proof → relevant next action. Never invent evidence or testimonials.
- Persuasive commentary: hook → assumption → supported explanation → insight → optional discussion. The former five-stage “Heartbeat Engine” is an option here when the source supports it.

Adapt pacing to duration; a 30-second film may combine functions within three clips, while a longer film can spend several clips demonstrating a mechanism. Do not manufacture secrets, contrarian claims or a universal truth to fill a template. Do not promise a completion-rate percentage from a script pattern. Close with the demonstrated takeaway, story payoff or requested CTA; a debate question is optional. Preserve supplied or approved copy unless a rewrite is requested or approved.

## One principal action, one emphasis

Default each ten-second clip to one readable principal physical action plus one supporting emphasis (for example, opening a blocked door followed by a close view of the obstacle). Add actions or effects only when needed to communicate the approved idea and feasible to generate clearly. There is no minimum effect/device count or mandatory change every two to three seconds.

Use setup → action → result as planning functions. `[0–3s]`, `[3–7s]`, `[7–10s]` are convenient timing examples, not compulsory boundaries. Specify actual intervals and states in each standalone prompt. An intentional reaction, evidence-reading or payoff hold is valid; name its purpose. Avoid unrelated spectacle, competing simultaneous actions and unexplained dead time. Prefer concrete actions over abstract liquid/shape morphing.

Check that the focal action is readable, the emphasis supports the narration, each prop transfer has a clear owner/state, and the ending connects to the next clip or closes the film. Increase density only after these checks pass. Existing examples illustrate possible treatments, not mandatory density or narrative templates.
